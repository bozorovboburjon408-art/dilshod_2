# ChemEdu Research

Kimyo ta'limi va ilmiy tadqiqot platformasi (sof HTML/CSS/JS, qaramliklarsiz).

Ishga tushirish: `cd chemedu && python3 -m http.server 8000` → http://localhost:8000
(yoki `index.html` ni to'g'ridan-to'g'ri brauzerda oching).

Bo'limlar: dars/slayd generatori va taqdimot, laboratoriya jurnali, ilmiy tadqiqot, dissertatsiya,
maqolalar (Crossref orqali onlayn qidiruv, iqtibos APA/ACS/GOST/BibTeX), davriy jadval, molekula 2D/3D
(SMILES, PubChem), reaksiya balanslash, SDS, 14 ta kalkulyator, talabalar, topshiriqlar, testlar,
AI yordamchi (lokal hisoblash motori), shablonlar, konferensiyalar, taqvim, loyiha/grantlar, sozlamalar.
Ma'lumotlar brauzerda (localStorage) saqlanadi; Sozlamalarda eksport/import mavjud.
